# Текущий контракт API

Базовый путь — `/api/v1`. Реализация находится в `services/api`, контракт — в `api/openapi.yaml`. Frontend обращается к Go API через same-origin proxy; готовых mock-режимов для обычного запуска нет. Тесты подменяют HTTP-ответы независимо от базы.

- `POST /auth/register` сохраняет временную заявку и отправляет шестизначный код на email. `POST /auth/register/verify` проверяет код, атомарно создаёт аккаунт и сразу устанавливает HttpOnly session cookie. Код действует 10 минут, после пяти неверных попыток заявка удаляется. Повторный `POST /auth/register` выпускает новый код. В локальном `mail.mode: log` код печатается в лог API; production использует SMTP.
- Публичный профиль содержит `region: string | null` — название региона, а не `region_id`. У водоёма сохраняется `region_id: UUID | null`.
- `PUT /auth/avatar` принимает JPEG или PNG до 5 МБ для текущего пользователя; сервер центрирует квадрат до 512 px, перекодирует его в JPEG и сохраняет в PostgreSQL. Исходные EXIF/GPS не хранятся и не публикуются. Обновлённый `User.avatar_url` указывает на публичный `GET /users/{id}/avatar` с версией в query string.
- DTO тем содержит `author_name` и `category_name`, DTO ответов и отчётов — `author_name`. Поля присутствуют и в OpenAPI. Для обычной темы `FeedItem.report` равен `null`.
- Неподдерживаемый параметр региона удалён из контракта ленты. Региональная лента требует отдельного согласования модели публикаций и SQL-фильтра; показывать региональный результат по глобальной выборке нельзя.
- Пагинация использует `{ items, next_cursor }`. Курсор указывает на последнюю возвращённую запись; следующая выборка строго после неё в порядке сортировки. Дополнительная запись при `limit + 1` только определяет наличие следующей страницы.
- Длины строк проверяются по символам Unicode: ник 3–32, заголовок 5–250, текст 1–20000, пароль 12–128; email не длиннее 254. Пароль не обрезается по краям.
- Загрузка фотографий в отчёты пока не реализована. Оба общих media upload endpoint и создание отчёта с непустым `media_ids` возвращают `501 NOT_IMPLEMENTED`; сервер не подтверждает сохранение вложений, которых нет. Загрузка аватара реализована отдельно.
- Точные GPS-координаты пока отсутствуют в модели API и не публикуются. Реализацию загрузки нельзя включать до серверной очистки EXIF/GPS. Флаг `location_visibility` не означает, что текст всего отчёта становится приватным.
- Подписка/отписка доступны через `POST /follows` и `DELETE /follows/{target_type}/{target_id}`. Получения списка подписок пока нет. Интерфейс честно обозначает этот раздел как готовящийся.
- Тема доступна по frontend-ссылке `/forum/topics/{id}`; уведомления могут вести прямо к обсуждению.

При изменении DTO, ограничений или путей обновляйте OpenAPI вместе с реализацией. Нереализованные будущие ответы upload API явно помечены как планируемые; фактический ответ сейчас — 501.
