# Перенос дизайна и план дальнейшего frontend

## Текущий статус

На Floot в оригинальном проекте есть главная `/`, концептуальные страницы `/v2`, `/v2/community`, `/v2/waters`, `/v2/water`, `/v2/assistant`, `/v2/market`, `/v2/profile`. Официальный архив исходников заблокирован тарифом.

Этот Vite starter — независимая реализация по согласованным референсам, **не идентичная побайтовая копия Floot**. Здесь уже работает главная и несколько MVP-страниц, новые разделы частично представлены заглушками. Ссылка на дизайн для визуальной сверки остаётся в аккаунте Floot владельца.

## Что приоритетно сделать в VS Code + Codex

1. Выполнить `npm install`, `npm run build`, `npm run dev` в `apps/web`; исправить, если появятся ошибки зависимости или типизации.
2. Сравнить стартовую страницу с Floot на 1440×900 и мобильных 393×852: меню, аватары/иконки, типографика, карточки, фото.
3. Отделить JSX на `features/forum`, `features/waters`, `features/profile` и `shared/ui`, сохранив визуал.
4. Сделать полноценные экраны: тема с цитированием и пагинацией, создание отчёта, поиск, профиль, регистрация/вход, уведомления, модерация.
5. Перенести все оригинальные фотографии/аватары из Floot Storage **только при наличии законного доступа и прав на использование**. Сейчас в проекте только оригинальная фотография владельца и её кадры как плейсхолдеры.
6. Реализовать API-слой через TanStack Query с типами, сгенерированными из OpenAPI; настоящие запросы включать после готовности Go API.
7. Валидация: безопасность XSS при пользовательских сообщениях, доступность с клавиатуры, мобильный UX и SEO для публичных тем.

## API

Контракт — `api/openapi.yaml`; текущие детали описаны в [API_NOTES.md](API_NOTES.md). В репозитории есть Go backend с PostgreSQL и миграциями. Frontend отправляет запросы через dev proxy `/api/v1` → `localhost:8080`. Для обычного локального запуска нужны работающие API и БД; при недоступности сервера интерфейс показывает ошибку и повтор запроса.

Реализованы загрузка следующих страниц ленты/форума/ответов/водоёмов/уведомлений, постоянная ссылка темы, доступные диалоги и мобильный поиск. Загрузка пользовательских фото и получение списка подписок ещё недоступны. Иллюстративным фотографиям интерфейса не приписываются реальные места.
