# Codex / KlevLiga

- Проект: КлёвЛига, рыболовная социальная сеть. Тема: dark first, «Глубокая вода», тёмный сине-графитовый фон и бирюзовый акцент.
- Изучи README.md, docs/ARCHITECTURE.md и docs/PORTING_NOTES.md прежде чем выполнять большие изменения.
- Frontend: apps/web, React + Vite + TypeScript. Не превращай интерфейс в шаблонный админ-дашборд; сохраняй характер и UX текущего дизайна.
- Это самостоятельно созданный Vite starter по дизайну Floot, не оригинальный экспорт. Сравнивай вручную со скриншотами Floot и дополняй отсутствующие экраны.
- Backend на Go разрабатывается отдельно; **не создавать Go-реализацию**, пока пользователь явно не попросит.
- API-контракт: api/openapi.yaml. Подключать реальный API по `/api/v1`; до готовности сервера использовать типизированные моки.
- Приватность рыболовных GPS-точек: скрыта по умолчанию. Не делай публичными EXIF, геоданные и личные сведения.
- Все фотографии водоёмов в текущем UI — иллюстративные; не приписывай им реальные географические места.
- При разработке: `cd apps/web && npm run build`, адаптивная проверка 393px и 1440px, проверка навигации клавиатурой, понятные ошибки.
- Создавай небольшие коммиты и документируй изменения API. Не храни секреты в репозитории.
